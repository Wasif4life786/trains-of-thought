# data/raw/signals (A1)

Raw inputs for world signals, as downloaded or hand-collected. Expected (contract.md §6.1):

- `stadiums.csv`: team aliases, stadium, lat, lon, capacity, nearest CRS
- `events.csv`: big concerts and events near hero stations (messy as found)
- `disruptions.json`: strikes and engineering works (hand-curated)
- saved API responses for tests, e.g. `open-meteo-MAN.json`, `openfootball-en1-2026-27.json`
- `snapshot/`: frozen live data for the offline demo (M3)
